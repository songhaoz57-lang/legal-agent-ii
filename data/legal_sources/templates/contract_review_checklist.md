# 合同审查清单（2025更新版）

## 一、主体资格审查

- [ ] 签约主体是否依法成立并有效存续
- [ ] 签约主体是否具备签署本合同的法定资格
- [ ] 法定代表人/授权代表是否具有合法授权
- [ ] 如为境外主体，是否完成公证认证手续
- [ ] 是否查询签约方的涉诉、失信被执行人信息

## 二、合同标的与核心条款

- [ ] 合同标的物/服务的描述是否明确、无歧义
- [ ] 数量、规格、质量标准是否可测量可验证
- [ ] 价款/报酬条款是否清晰（币种、金额、大写）
- [ ] 支付方式、期限、账户信息是否完整
- [ ] 发票类型、税率、开票时间是否约定明确
- [ ] 交付/履行地点、方式、期限是否明确
- [ ] 验收标准与验收程序是否约定

## 三、合同效力审查

- [ ] 是否违反法律强制性规定（如非法集资、传销、赌博等）
- [ ] 是否违反公序良俗
- [ ] 是否涉及无权处分
- [ ] 审批/备案等生效要件是否明确
- [ ] 附条件/附期限条款的表述是否清晰

## 四、违约责任条款

- [ ] 违约情形是否列举完备（延迟履行、瑕疵履行、不履行等）
- [ ] 违约金比例是否合理（一般不超过损失30%）
- [ ] 是否有定金条款（定金罚则不得超过合同金额20%）
- [ ] 是否有损失赔偿的计算方式或范围约定
- [ ] 是否有违约金与定金的选择适用条款
- [ ] 继续履行与解除合同的触发条件是否明确

## 五、权利义务对等性审查

- [ ] 是否存在显失公平的单方条款
- [ ] 是否过度限制对方主要权利
- [ ] 是否免除己方主要义务
- [ ] 是否有不合理的格式条款（接受or不接受，无可协商）
- [ ] 权利义务是否平衡合理

## 六、合同终止与解除

- [ ] 解除合同的条件是否明确
- [ ] 解除后的清算条款是否完整
- [ ] 是否有后合同义务条款（保密、竞业禁止、协助等）
- [ ] 合同期限与自动续期条款是否合理

## 七、知识产权条款（如涉及）

- [ ] 知识产权归属是否明确
- [ ] 是否约定了知识产权侵权责任
- [ ] 许可范围（独占/排他/普通）是否清晰
- [ ] 技术成果的后续改进权利归属
- [ ] AI生成内容的权利归属与责任承担

## 八、保密条款

- [ ] 保密信息的范围是否明确
- [ ] 保密期限是否合理
- [ ] 违反保密义务的违约责任是否具有威慑力
- [ ] 是否约定了保密信息的归还/销毁义务

## 九、数据合规与个人信息保护（如涉及）

- [ ] 是否涉及个人信息收集与处理
- [ ] 是否约定了数据处理的目的、方式、范围
- [ ] 是否有数据安全保护措施条款
- [ ] 是否有数据泄露通知义务条款
- [ ] 跨境数据传输是否需要进行安全评估

## 十、争议解决条款

- [ ] 争议解决方式是否明确（诉讼or仲裁，二选一）
- [ ] 管辖法院/仲裁机构约定是否合法有效
- [ ] 是否约定了适用法律（境内/境外）
- [ ] 是否约定了送达地址

## 十一、不可抗力条款

- [ ] 不可抗力的范围是否界定清楚
- [ ] 是否约定了不可抗力发生后的通知义务
- [ ] 是否约定了不可抗力下的责任豁免与合同处理方式

## 十二、附则与签署

- [ ] 合同份数与语言版本是否约定
- [ ] 是否约定合同生效条件
- [ ] 是否有完整的签署栏（名称、盖章、日期）
- [ ] 附件是否完整并作为合同组成部分
